# Maelzel

피아노 연습용 메트로놈. 빌드 도구 없이 정적 파일만으로 동작합니다.

## 로컬에서 열기

서비스 워커와 폰트 로딩 때문에 파일을 직접 여는 것(`file://`) 대신 서버로 띄워야 합니다.

`serve.command` 를 **더블클릭**하면 서버가 뜨고 브라우저가 자동으로 열립니다.
끄려면 열린 터미널 창에서 `Control-C`.

터미널을 직접 쓰려면:

```sh
cd ~/Desktop/coding/metronome
python3 -m http.server 8000
```

브라우저에서 `http://localhost:8000` 접속. **서버를 켜둔 동안에만 열립니다** —
창을 닫으면 페이지도 안 열립니다.

같은 와이파이의 폰에서 보려면 맥의 IP를 확인해 `http://<맥IP>:8000` 으로 들어가면 됩니다.

```sh
ipconfig getifaddr en0
```

> 폰에서 테스트할 때 주의: **소리는 나지만 홈 화면 설치와 오프라인은 HTTPS에서만** 동작합니다.
> 로컬 IP는 HTTP라 서비스 워커가 등록되지 않습니다. 아래처럼 배포한 뒤 확인하세요.

## 배포

**https://ayun-jeong.github.io/metronome/**

GitHub Pages로 `main` 브랜치에서 바로 서빙됩니다. 빌드 단계가 없으니 푸시가 곧 배포입니다.

```sh
git add -A
git commit -m "무엇을 고쳤는지"
git push
```

1분 안쪽으로 반영됩니다.

아이폰 사파리에서 위 주소를 열고 **공유 → 홈 화면에 추가**하면 앱처럼 전체 화면으로 실행되고,
오프라인에서도 켜집니다.

## 파일

| 파일 | 내용 |
|---|---|
| `index.html` | 화면 구조와 메타 태그 |
| `styles.css` | 전체 스타일. 라이트·다크 두 벌의 색 토큰이 맨 위에 있습니다 |
| `app.js` | 스케줄러, 소리 합성, 즐겨찾기, 곡 구간, 코드 검색 |
| `chords.js` | 코드 420개 데이터 (21개 루트 × 20개 코드 종류) |
| `sw.js` | 서비스 워커. 캐시에서 즉시 열고 뒤에서 갱신합니다 |
| `manifest.webmanifest` | 홈 화면 설치 정보 |
| `assets/` | 서브셋한 Pretendard 폰트, 아이콘 |

## 알아둘 것

**타이밍.** `setInterval`로 소리를 직접 내지 않습니다. 25ms마다 깨어나 앞으로 울릴 클릭을 오디오 클럭에 **예약만** 합니다(`scheduler()` 참고). JS 타이머가 흔들려도 발음 시각은 흔들리지 않습니다. 이 구조를 바꾸면 박자가 밀립니다.

예약 창은 화면이 보일 때 100ms, 숨겨지면 1.6초입니다. 브라우저가 백그라운드 타이머를 1초 간격으로 조이기 때문에, 창이 좁으면 깨어남 사이에 박이 지나가 버립니다. 이미 지나간 박은 예약하지 않고 건너뜁니다 — 예약하면 오디오 스레드가 즉시 발음해서 여러 개가 한 순간에 겹쳐 한 번의 큰 소리로 뭉칩니다.

**백그라운드 한계.** iOS에서는 화면을 끄거나 앱을 나가면 웹앱의 오디오가 멈춥니다. WebKit의 알려진 제약이라 웹에서는 우회할 방법이 없습니다([198277](https://bugs.webkit.org/show_bug.cgi?id=198277)). 그래서 재생 중에는 Wake Lock으로 화면을 켜둡니다. 화면을 끈 채 쓰시려면 네이티브 앱이 필요합니다.

**소리.** 클릭은 밴드패스 노이즈(2.6~4.2kHz)와 짧은 음정 성분을 겹친 것입니다. 그 대역이 사람 귀에 가장 민감하고 피아노 에너지는 상대적으로 적어서, 볼륨을 키우지 않고도 뚫고 나옵니다. 출력은 리미터를 거쳐 유니티의 2.2배까지 올려두었습니다.

**화면 유지.** 재생 중에는 Wake Lock으로 화면이 꺼지지 않게 합니다. 화면이 꺼지면 iOS가 오디오를 멈추기 때문에 선택이 아니라 필수입니다. 사파리 탭은 iOS 16.4+, 홈 화면 앱은 18.4+ 에서 동작합니다.

**애니메이션.** 화면 갱신 루프는 재생 중에만 돕니다. 정지하면 취소됩니다(`startFrames` / `stopFrames`).

**대소문자.** 코드 검색에서 `Cm7`(마이너)과 `CM7`(메이저)은 다른 코드입니다. 첫 글자만 대문자로 맞추고 나머지는 입력 그대로 씁니다.

## 저장되는 것

브라우저 로컬 저장소(`localStorage`)에 남습니다. 앱을 껐다 켜도 그대로 복원됩니다.

- `maelzel.theme` — 라이트/다크 선택
- `maelzel.favs` — 템포 즐겨찾기 6칸
- `maelzel.songfavs` — 곡 즐겨찾기 6칸
- `maelzel.song` — 편집 중인 곡

**iOS 주의.** 사파리는 어떤 사이트를 **7일 동안 안 열면** 그 사이트의 저장 데이터를 지웁니다.
홈 화면에 추가한 앱은 사파리와 별도의 사용 일수 카운터를 가지며, 앱을 열 때마다 초기화됩니다.
그래서 **홈 화면에 추가해서 쓰는 쪽이 훨씬 안전합니다.**

앱은 켜질 때 `navigator.storage.persist()` 로 영구 저장 모드를 요청합니다. 허가되면
이 정리 대상에서 아예 빠집니다. 브라우저가 사용 빈도를 보고 판단하므로 항상 허가되지는
않습니다.

브라우저 데이터를 직접 지우면 어느 경우든 함께 사라집니다.

## 수정하기

파일을 고치고 새로고침하면 됩니다. 서비스 워커가 캐시에서 먼저 열기 때문에 **바뀐 내용은 새로고침 한 번 뒤에 반영**됩니다. 바로 보고 싶으면 개발자도구에서 캐시를 비우거나, 시크릿 창에서 여세요.
